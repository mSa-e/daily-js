# js-challenges

A collection of JavaScript challenges I solve to practice fundamentals
and track my progress.

## Structure

Each challenge is in its own folder with a `solution.js`, `helper.html` and `challenge.md`.

- `solution.js` : The Javascript solution file
- `helper.html` : The `.html` file that we'll see our output from using the `console` tab in the `devtools`
- `challenge.md` : Challenge description

## Sources

Codewars, LeetCode, and random ideas.

## Progress

Updated as I solve new challenges.
